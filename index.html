ENTERPRISE RAG APPLICATION PRODUCTION DEPLOYED

DocTalk – RAG-Based PDF Q&A Web Application

An intelligent document conversational agent eliminating manual enterprise document search by pairing TF-IDF passage retrieval with Claude API contextual grounding.

Python Flask TF-IDF Vectorization Claude API RAG Pipeline NLP
01
Document Ingestion & Chunking
Multi-page enterprise PDFs are streamed through text parsers, sanitized, and segmented into overlapping text chunks to preserve local semantic context.
↓
02
TF-IDF Vector Indexing
Passages are transformed into numerical vector matrices using term frequency-inverse document frequency weighting, optimizing low-latency passage indexing.
↓
03
Top-K Passage Retrieval
Natural language user queries are vectorized in real-time, executing cosine similarity scoring to isolate the most relevant candidate passages.
↓
04
Context Injection & Claude Inference
The retrieved passages are injected into an engineered prompt template sent to the Claude API, generating grounded, hallucination-free answers with verbatim citations.

// THE BOTTLENECK

Enterprise analysts and technical personnel frequently lose critical hours manually skimming dense 10+ page technical manuals, whitepapers, and operational handbooks. Generic LLMs hallucinate facts when asked specific domain questions without direct reference access, while passing entire documents into raw prompts exceeds token budgets and escalates API costs dramatically.

Design Objective: Engineer a lightweight, local-indexing RAG web application that retrieves precise document evidence sub-second and feeds only high-signal passages to Claude for reliable question answering.

DEEP LEARNING • COMPUTER VISION INCEPTIONV3 ARCHITECTURE

Gender Detection via Deep Learning (InceptionV3)

High-performance binary facial image classification leveraging Transfer Learning on pre-trained InceptionV3 CNN weights, fine-tuned with domain-specific regularization.

Python TensorFlow Keras InceptionV3 OpenCV Data Augmentation
01
Input Preprocessing & Facial Framing (OpenCV)
Facial regions are isolated using Haar-cascade/SSD detectors, normalized to 299x299 RGB resolution, and rescaled for neural network tensor ingestion.
↓
02
Data Augmentation Pipeline
Applied dynamic transformations (random rotation ±20°, horizontal flips, brightness shifts, and zoom factor 0.2) to systematically prevent overfitting on scarce training splits.
↓
03
InceptionV3 Feature Extractor
Loaded ImageNet pre-trained weights with frozen lower convolutional layers to preserve low-level spatial filter representations (edges, textures, silhouettes).
↓
04
Classification Head & Fine-Tuning
GlobalAveragePooling2D layer coupled with a Dropout (0.4) layer and a Dense sigmoid output head, trained with Adam optimizer and binary cross-entropy loss.

// THE CHALLENGE

Standard deep convolutional neural networks trained from scratch on constrained facial image datasets suffer from severe overfitting, high variance, and poor generalization across varying lighting conditions, facial occlusions, and diverse demographics.

Design Objective: Harness the rich multi-scale feature hierarchies of InceptionV3 via Transfer Learning, reducing training epoch requirements while maximizing generalization on held-out test splits.
